# 数据字典

- run_id：规则版本与输入 SHA-256 前 12 位组成的稳定批次标识。
- line_no：从 1 开始的物理来源行号，不因隔离或排序改变。
- business_key：本项目声明的业务唯一键，始终按字符串存储。
- reason_code：隔离原因的稳定英文编码。
- accepted：进入业务计算的记录数。
- quarantined：保留证据但不参与业务计算的记录数。
- 数值：金额、税额、用量和权重使用 Decimal；对外序列化为字符串。
- 时间：存储为带偏移的 ISO 8601，分桶使用半开区间。
- 空值：缺失键、空串和业务哨兵分别记录。
- 幂等：完整输入字节与规则版本相同则复用 run_id，不新增结果。
- 关账快照（closed_batches）：关账时冻结的原批次税额、含税额与按 business_key 的明细快照；更正流程只读不写，审计数字与关账保持一致。
- 税额更正（tax_adjustments）：更正单采信后，新旧税额差额以带符号 Decimal 进入差异批次，调低为负。correction_no 为唯一键，重跑同一张更正单不重复入账。
- source_run_id：调整所属的原关账批次标识，差异批次页面据此从调整追溯到原批次。
